# نظام صندوق استثماري ذكي متوافق مع الشريعة (Shariah‑AI Investment Fund)

> وثيقة تشغيلية مختصرة قابلة للتحويل مباشرة إلى خطة تنفيذ تقنية.

## 1) الملخص التنفيذي

يهدف المشروع إلى بناء منصة استثمارية ذكية تدير دورة الاستثمار كاملةً بدءًا من جمع البيانات، مرورًا بالفحص الشرعي والتحليل المالي، وصولًا إلى تخصيص الأصول وإعادة التوازن تلقائيًا.

**مخرجات النظام الأساسية:**
- قائمة أصول متوافقة مع الشريعة ومحدثة باستمرار.
- تقييم مالي/سوقي/شرعي لحظي لكل أصل.
- توصيات تخصيص أوزان ديناميكية للمحفظة.
- تنبيهات مخاطر وتشغيل ولوحة متابعة موحدة.

## 2) الأهداف الاستراتيجية

- رفع جودة القرار الاستثماري عبر نماذج تعلم آلي قابلة للتحقق.
- تقليل التحيز والأخطاء البشرية في إدارة المحافظ.
- تحقيق امتثال شرعي مستمر وقابل للتدقيق (Auditability).
- تحسين العائد المعدّل بالمخاطر ضمن قيود سياسة الصندوق.

## 3) نطاق النظام

### 3.1 فئات الأصول المستهدفة
- الأسهم.
- العملات الرقمية المتوافقة مع السياسات الشرعية المعتمدة.
- الصناديق الاستثمارية المتوافقة.
- الصكوك.
- أدوات دخل/أصول بديلة (وفق توفر البيانات والضوابط الشرعية).

### 3.2 الفئات المستفيدة
- المستثمر الفردي الباحث عن استثمار متوافق مع الشريعة.
- مدراء الأصول والصناديق.
- منصات التداول الراغبة في دمج محرك توصية شرعي.

## 4) المعمارية التقنية (Architecture)

## 4.1 طبقة البيانات (Data Layer)

**المصادر:**
- أسعار تاريخية ولحظية (أسهم/كريبتو/مؤشرات).
- بيانات مالية للشركات (قوائم، نسب، إفصاحات).
- بيانات نصية (تقارير سنوية، أوصاف الأنشطة).
- بيانات أصول بديلة (صكوك/عقار عند توفر واجهات موثوقة).

**خط الأنابيب (Pipeline):**
1. Ingestion (API/Batch/Streaming).
2. Validation & Cleaning.
3. Feature Store (ميزات زمنية، مالية، شرعية).
4. Time-series Warehouse + Metadata Catalog.

## 4.2 طبقة الذكاء الاصطناعي (AI/ML Layer)

### أ) نموذج التوافق الشرعي (Shariah Compliance Model)
- تصنيف النشاط الاقتصادي (مسموح/مقيد/مرفوض).
- قياس نسب مالية شرعية (ديون، سيولة، فوائد... حسب السياسة).
- إنتاج **Shariah Score** مع تفسير لأسباب القبول/الرفض.

### ب) نماذج التنبؤ (Forecasting Models)
- نماذج سلاسل زمنية/تعلم عميق لتوقع:
  - اتجاه السعر.
  - التقلب (Volatility).
  - احتمالات الهبوط الحاد.

### ج) وكيل التعلم المعزز (RL Allocation Agent)
- الحالة (State): خصائص السوق، المخاطر، التوافق الشرعي، السيولة.
- الفعل (Action): أوزان المحفظة المقترحة.
- المكافأة (Reward): عائد معدّل بالمخاطر + عقوبات لمخالفات شرعية/تجاوز المخاطر.
- القيود: حدود تمركز، سيولة، انكشاف قطاعي، وسياسة شرعية.

## 4.3 طبقة دعم القرار (Decision Support)
- توصيات إضافة/إزالة أصل.
- اقتراح وزن الأصل مع تفسير ثقة النموذج.
- تنبيهات تلقائية (مخاطر، تغير توافق شرعي، انحراف عن سياسة الصندوق).

## 4.4 الواجهة (Dashboard)
- حالة المحفظة اللحظية.
- خريطة التوافق الشرعي للأصول.
- مؤشرات الأداء (Return, Sharpe, Max Drawdown, Turnover).
- سجل قرارات النماذج (Model Decision Log).

## 5) التدفقات التشغيلية (Core Flows)

1. **Data Pull**: جلب دوري + مراقبة جودة.
2. **Preprocessing**: تنظيف، مواءمة زمنية، بناء الميزات.
3. **Shariah Screening**: تقييم شرعي رقمي وتفسير أسباب القرار.
4. **AI Evaluation**: تقدير عائد/مخاطر وتقييم شامل للأصل.
5. **Portfolio Optimization**: تخصيص أوزان وإعادة توازن آلية.
6. **Execution Interface**: إخراج توصيات أو أوامر تداول (حسب صلاحيات البيئة).
7. **Monitoring & Audit**: مراقبة الأداء والامتثال والتراجع (Backtesting/Live).

## 6) المتطلبات غير الوظيفية

- **الشفافية:** كل قرار يجب أن يكون قابلًا للتفسير والتدقيق.
- **الاعتمادية:** آلية تعافٍ تلقائي للبيانات الفاشلة والانقطاعات.
- **الأمان:** تشفير البيانات الحساسة وإدارة صلاحيات دقيقة.
- **القابلية للتوسع:** تصميم معياري يسمح بإضافة أسواق/أصول/نماذج جديدة.
- **الامتثال:** سياسات شرعية قابلة للتحديث دون كسر المنظومة.

## 7) مؤشرات النجاح (KPIs)

- معدل دقة نموذج التوافق الشرعي.
- نسبة الأصول المتوافقة ضمن الكون الاستثماري.
- العائد المعدّل بالمخاطر مقابل مؤشر مرجعي.
- زمن الاستجابة من الإشارة إلى التوصية.
- نسبة قرارات يمكن تفسيرها بالكامل (Explainability Coverage).

## 8) خارطة الطريق التنفيذية (Roadmap)

### المرحلة 1 (MVP Data + Screening)
- بناء طبقة بيانات موحدة.
- إطلاق نموذج توافق شرعي أولي.
- لوحة مراقبة أساسية + تقارير يومية.

### المرحلة 2 (Forecasting + Optimization)
- دمج نماذج التنبؤ بالعائد/المخاطر.
- محرك تخصيص أولي بقيود شرعية ثابتة.
- Backtesting متعدد السيناريوهات.

### المرحلة 3 (RL + Advanced Governance)
- تطوير وكيل RL لإعادة التوازن الديناميكي.
- حوكمة نماذج (Versioning, Drift, Retraining).
- سجل قرارات تفصيلي لأغراض التدقيق.

### المرحلة 4 (Production + Integration)
- نشر إنتاجي مع مراقبة لحظية.
- API للتكامل مع مزودي التنفيذ/التداول.
- سياسات تحديث تلقائي للبيانات والنماذج.

## 9) المخاطر الرئيسية وخطة التخفيف

- **جودة البيانات:** اعتماد مزودين متعددين + قواعد تحقق صارمة.
- **انحراف النماذج (Model Drift):** مراقبة أداء مستمرة وإعادة تدريب دورية.
- **تعارض التفسير مع الأداء:** موازنة بين دقة النموذج وقابلية تفسيره.
- **اختلاف المعايير الشرعية:** طبقة قواعد مرنة قابلة للتهيئة حسب الهيئة الشرعية.

## 10) مراجع إلهامية

- Numerai كمثال لصناديق تعتمد الذكاء الاصطناعي في اتخاذ القرار.
- أبحاث التعلم المعزز في إدارة المحافظ المالية.
- توجهات الاستثمار الكمي المدعوم بالذكاء الاصطناعي في المؤسسات الحديثة.
